# 💻 BUP Event Calendar

A C-based academic calendar project for Bangladesh University of Professionals (BUP).

## 📌 Project Overview
BUP Event Calendar is a console-based application developed using C programming. It displays academic schedules, holidays, examinations, and university events through an interactive calendar.

## ✨ Features
- Interactive Monthly Calendar
- Academic Events and Holidays
- Semester Examination Schedule
- Specific Date Search
- Month and Year Navigation
- Government Holiday Detection
- Weekly Holiday Information

## 🛠️ Technologies Used
- C Programming Language
- Structures
- Arrays
- Functions
- Date Calculation

## ▶️ How to Run
Compile and run the source code using a Windows-compatible C compiler that supports `conio.h` and `_getch()`.
